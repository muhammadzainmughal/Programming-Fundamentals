# CS-1101 Programming Fundamentals – C++ Lab Tasks

This repository contains C++ programs developed as part of **CS-1101: Programming Fundamentals**.  
The projects focus on core C++ concepts such as variables, constants, data types, operators, and user input/output.

---

## 📚 Topics Covered

- Variables and Constants  
- Data Types in C++  
- Assignment Statements  
- Arithmetic Operations  
- User Input (`cin`) and Output (`cout`)  
- Mathematical Calculations  
- Formatting Output  

---

## 🧪 Lab Tasks Included

### ✅ Task 1: Arithmetic Operations
- Performs addition, subtraction, multiplication, division, and modulus
- Uses both predefined values and user input

### ✅ Task 2: Distance Calculator
- Calculates the **squared distance** between two points in a 2D plane

### ✅ Task 3: Total Purchase Calculation
- Calculates subtotal, sales tax (6%), and total amount
- Demonstrates use of constants

### ✅ Task 4: Average of Test Scores
- Calculates average of predefined test scores
- Displays result rounded to two decimal places

### ✅ Task 5: BMI Calculator
- Calculates Body Mass Index using user-provided weight and height

### ✅ Task 6: Trip Cost Calculator
- Estimates total fuel cost based on distance, fuel efficiency, and fuel price
