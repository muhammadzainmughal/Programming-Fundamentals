# CS-1101 Programming Fundamentals – Lab 10

This repository contains C++ programs developed for **Lab 10** of **CS-1101: Programming Fundamentals**.  
The lab focuses on **repetition control using the `for` loop** to efficiently perform tasks with a known number of iterations.

## 🎯 Lab Objectives

- Understand the working of the **for loop**
- Use `for` loop for repetitive tasks
- Compare `for` loop with other looping constructs
- Solve mathematical and pattern-based problems using loops

---

## 📚 Topics Covered

- Control Structures  
- Repetition Control Structures  
- `for` loop  
- Infinite loops  
- Pattern printing

## 🧪 Lab Tasks

### ✅ Basic Tasks Using `for` Loop

- Print numbers from **1 to N**
- Display the **multiplication table** of a number
- Calculate the **sum of first N natural numbers**
- Print different **patterns** using loops
- Calculate **factorial** of a number
  - Displays an error message for negative input
