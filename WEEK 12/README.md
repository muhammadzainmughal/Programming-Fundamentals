# CS-1101 Programming Fundamentals – Lab 11

This repository contains C++ programs developed for **Lab 11** of **CS-1101: Programming Fundamentals**.  
The lab focuses on understanding and implementing **functions in C++**, including **library functions** and **user-defined functions**.

## 🎯 Lab Objectives

- Understand the concept of **functions**
- Learn function declaration, calling, and prototyping
- Use **parameters** and **return statements**
- Implement **library** and **user-defined** functions
- Build **menu-driven programs** using functions

---

## 📚 Topics Covered

- Functions in C++
- Function declaration and definition
- Function calling
- Parameters and return values
- Function prototyping
- Library functions vs user-defined functions
