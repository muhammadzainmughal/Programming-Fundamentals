# CS-1101 Programming Fundamentals – Lab 04 (Operators in C++)

This repository contains C++ programs developed for **Lab 04** of **CS-1101: Programming Fundamentals**.  
The lab focuses on understanding and applying different types of **operators** in C++ along with **operator precedence** and **ternary logic**.

---

## 📘 Lab Overview

**Lab Title:** Operators in C++  
**Course:** CS-1101 – Programming Fundamentals  
**Instructor:** Engr. Muhammad Awais  

---

## 🎯 Lab Objectives

- Apply **arithmetic, relational, logical, assignment, and ternary operators**
- Understand **operator precedence and associativity**
- Solve real-world problems using operators
- Avoid `if-else` where ternary operators are required

---

## 📚 Topics Covered

### 🔢 Arithmetic Operators
- `+` Addition  
- `-` Subtraction  
- `*` Multiplication  
- `/` Division  
- `%` Modulus  

### 🔍 Relational Operators
- `==`, `!=`, `<`, `>`, `<=`, `>=`

### 🔗 Logical Operators
- `&&` Logical AND  
- `||` Logical OR  
- `!` Logical NOT  

### 🧮 Assignment Operators
- `=`, `+=`, `-=`, `*=`, `/=`

### ❓ Ternary Operator
- `condition ? expression1 : expression2`

### ⚖️ Operator Precedence
- Evaluation order of expressions involving multiple operators

---

## 🧪 Lab Tasks

### ✅ Task 1: Even or Odd Checker
- Determines whether a number is **even or odd**
- Uses the **ternary operator**
- No `if-else` allowed

### ✅ Task 2: Age Group Classification
- Classifies age as:
  - Child
  - Teenager
  - Adult
- Implemented using **nested ternary operators**

### ✅ Task 3: Banking Application
- Determines:
  - Account type (Low, Standard, Premium)
  - Special offer eligibility
- Uses **ternary + logical operators**
- No `if-else` statements
