# CS-1101 Programming Fundamentals – Lab 08

This repository contains C++ programs developed for **Lab 08** of **CS-1101: Programming Fundamentals**.  
The lab focuses on **decision control using the `switch` statement** to handle multiple user-driven choices efficiently.

---

## 📘 Lab Details

- **Lab Number:** 08  
- **Course:** CS-1101 – Programming Fundamentals  
- **Instructor:** Engr. Muhammad Awais  
- **Date:** December 10, 2024  
- **Topic:** `switch` Statement in C++

---

## 🎯 Lab Objectives

- Learn how to use the **switch statement** in C++
- Control program flow based on discrete user inputs
- Apply switch-case logic to real-world problems
- Understand rules and limitations of switch statements

---

## 📚 Topics Covered

- Control Structures  
- Decision Control Structures  
- `switch` statement  
- `case`, `break`, and `default`  
- Switch rules and fall-through behavior  

---

## 🧪 Lab Tasks

### ✅ Basic Switch Tasks

- **Simple Calculator**
  - Performs `+`, `-`, `*`, `/` operations
  - Displays error for invalid operators

- **Day of the Week**
  - Converts numbers (1–7) into corresponding weekdays
  - Handles invalid input

- **Area Calculator**
  - Calculates area of:
    - Circle
    - Rectangle
    - Triangle

---

### ✅ Additional Switch Tasks

- **Currency Converter**
  - Converts USD to:
    - PKR
    - INR
    - Euros
  - Uses predefined exchange rates

---

### ✅ Mini Project: Shopping System with Invoice

- Categories:
  - Electronics
  - Clothing
  - Groceries
- Item selection using switch
- Quantity-based total calculation
- Discount rules:
  - Below $100 → No discount
  - $100–$500 → 10% discount
  - Above $500 → 20% discount
- Generates a final invoice
