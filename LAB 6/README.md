# CS-1101 Programming Fundamentals – Lab 05

This repository contains C++ programs for **Lab 05** of **CS-1101: Programming Fundamentals**.  
The lab focuses on **control structures** and **decision-making using if and if-else statements**.

---

## 📘 Lab Details

- **Lab:** 05  
- **Course:** CS-1101 – Programming Fundamentals  
- **Instructor:** Engr. Muhammad Awais  
- **Topic:** Control Structures (if / if-else)

---

## 🎯 Objectives

- Understand program flow control
- Use `if` and `if-else` statements
- Implement decision-based logic in C++

---

## 🧪 Tasks Included

### 🔹 Using `if` Statements
- Positive number checker  
- Even number checker  
- Largest of three numbers  
- Student grade calculator  
- Traffic signal simulation  

### 🔹 Challenge Task
- Employee Payroll Management System  
  - Salary calculation  
  - Bonus and tax deduction  
  - **Only `if` statements used**

### 🔹 Using `if-else`
- ATM withdrawal system  
- Loan eligibility checker
