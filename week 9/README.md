# CS-1101 Programming Fundamentals – Lab 09

This repository contains C++ programs developed for **Lab 09** of **CS-1101: Programming Fundamentals**.  
The lab focuses on **repetition control structures**, specifically **while** and **do-while** loops.

---

## 📘 Lab Details

- **Lab Number:** 09  
- **Course:** CS-1101 – Programming Fundamentals  
- **Instructor:** Engr. Muhammad Awais  
- **Topic:** While Loop & Do-While Loop  

---

## 🎯 Lab Objectives

- Understand the need for loops in programming
- Learn **entry-controlled** and **exit-controlled** loops
- Use **while** loops for repeated execution
- Use **do-while** loops where execution must occur at least once
- Build menu-driven programs using loops

---

## 📚 Topics Covered

- Control Structures  
- Repetition Control Structures  
- `while` loop  
- `do-while` loop  
- Infinite loops  
- Menu-driven programs  

---

## 🧪 Lab Tasks

### ✅ Tasks Using `while` Loop

- Print numbers from **1 to N**
- Display **multiplication table** of a number
- Validate positive number input
- Calculate the **sum of first five natural numbers**
- **Menu-driven banking system**:
  - Deposit money
  - Withdraw money
  - Check balance
  - Exit program

---

### ✅ Tasks Using `do-while` Loop

- **Password verification system**
  - Keeps asking until correct password is entered

- **Restaurant Ordering System**
  - Menu and sub-menu selection
  - Fixed item prices
  - Quantity-based ordering
  - Continuous ordering until user exits
  - Final bill calculation
