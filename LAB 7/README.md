# CS-1101 Programming Fundamentals – Lab 07

This repository contains C++ programs developed for **Lab 07** of **CS-1101: Programming Fundamentals**.  
The lab focuses on **advanced decision control structures**, specifically the **if-else-if ladder** and **nested if statements**.
