# CS-1101 Programming Fundamentals – Lab 13

This repository contains C++ programs developed for **Lab 13** of **CS-1101: Programming Fundamentals**.  
The lab focuses on understanding and applying **pointers in C++**, including dereferencing, pointer types, pointer arithmetic, and call-by-reference.

---

## 📘 Lab Details

- **Lab Number:** 13  
- **Course:** CS-1101 – Programming Fundamentals  
- **Instructor:** Engr. Muhammad Awais  
- **Date:** February 18, 2025  
- **Topic:** Pointers in C++

---

## 🎯 Lab Objectives

- Understand the concept of **pointers**
- Learn **dereferencing operators**
- Explore different **types of pointers**
- Use **pointer arithmetic**
- Understand **array names as pointers**
- Apply **call-by-reference** using pointers

---

## 📚 Topics Covered

- Pointer declaration and initialization
- Address-of (`&`) and dereference (`*`) operators
- Invalid pointers
- NULL / nullptr pointers
- Void pointers and type casting
- Call-by-reference using pointers
- Array name as pointer
- Pointer arithmetic

---

## 🧪 Lab Tasks

### ✅ Basic Pointer Tasks

- Display the value of a variable using a pointer
- Modify a variable’s value using a pointer
- Access and display array elements using pointer arithmetic

---

### ✅ Function & Pointer Tasks

- Swap two numbers using a function with pointer parameters
- Demonstrate **call-by-reference**

---

### ✅ Special Pointer Tasks

- Declare and check a **nullptr**
- Display appropriate message if pointer is null
- Use a **void pointer** to store and access an integer value
  - Typecasting before dereferencing

---

- Research and explain **dynamic memory allocation using pointers**
