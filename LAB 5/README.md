# CS-1101 Programming Fundamentals – Lab 05 (Control Structures)

This repository contains C++ programs developed for **Lab 05** of **CS-1101: Programming Fundamentals**.  
The lab focuses on **control structures**, specifically **decision control using `if` and `if-else` statements** to control program flow.

---

## 📘 Lab Overview

- **Lab Number:** 05  
- **Course:** CS-1101 – Programming Fundamentals  
- **Instructor:** Engr. Muhammad Awais  
- **Topic:** Control Structures & Decision Making  

---

## 🎯 Lab Objectives

- Understand **control structures** in C++
- Apply **if** and **if-else** statements
- Control program flow based on conditions
- Solve real-world problems using decision logic

---

## 📚 Topics Covered

### 🔁 Control Structures
- Sequential Flow  
- Conditional Flow  
- Repetitive Flow (conceptual)

### 🔀 Decision Control Structures
- `if` statement  
- `if-else` statement  

---

## 🧪 Lab Tasks

### ✅ Basic Tasks (Using `if` Only)

- Check if a number is **positive**
- Check if a number is **even**
- Find the **largest of three numbers**
- Determine **student grade** based on marks
- Simulate a **traffic signal system**

---

### ✅ Challenge Task: Employee Payroll Management System

- Determines **basic salary** based on employee grade
- Calculates **bonus** based on years of service
- Applies **tax deduction** based on gross salary
- Calculates **net salary**
- **Restriction:** Uses **only `if` statements**

---

### ✅ Basic Tasks (Using `if-else`)

- ATM withdrawal system
- Loan eligibility checker based on salary and experience
